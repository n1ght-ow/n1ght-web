# N1GHT CHXN9 · 万象游乐场

本轮将十个收藏类别设计为可直接操纵的空间装置。访客通过拖拽、按压、拨动与重组改变模型，看到可解释的结构联动与结果。私人收藏是机构里的材料，详情弹窗继续承担深入阅读。原网页完整保留于 reading.html，/myscore/ 维持独立赛事页面。

## 视觉与建模

方向为精密雕塑、非现实建筑与可玩的机械剧场。暖灰背景、白瓷、胡桃木、氧化铜、黑漆、纸纤维和少量宝石色光提供统一气质；真实照片、封面和绘画保留原色。不同装置有自己的分裂地层、支座、悬臂和轮廓，不再使用统一圆形展示底盘。

复杂度落实到内外结构：多层镜片和光圈叶片、巨型卷页与折纸屋面、悬挑阅览塔、莫比乌斯字带、二十四片画面、张弦与共振叶片、曲面看台与网罩、分岔桥梁、穿孔胶片、可旋转道路、舞台轨道与配重。曲面使用参数几何，重复结构实例化；结构运动有自己的状态，不以随机旋转或打开弹窗冒充玩法。

结构精修采用分开的前、中、后层：前侧为作品和握持区，中间容纳活动部件及其完整行程，后侧布置支撑与传动。导向结构只露必要运动段，配合端盖、轴套、连接座和刻度；不让装饰长杆穿过作品、画框或操作区。保持每件装置的独特轮廓，不通过固定镜头掩盖结构冲突。

## 十件装置

- **光谱折叠暗房 / 摄影**：拖动十二叶光圈和伸缩镜组，改变进光与清晰度；拖胶片换真实照片，按模型快门完成曝光与印相纸显影。显影后的作品可继续阅读。
- **无尽翻页书城 / 书籍**：错层书列、悬挑阅览塔、折纸拱壳与大开本交错。拉动导轨展开建筑，拖页角连续卷曲翻页，转曲柄选择真实藏书。
- **月引诗潮 / 诗歌**：月牙牵引字带和悬浮纸页；墨池受点按/拖动产生涟漪并推进真实诗句，曲面纸卷逐节展开原诗。
- **维度解构画室 / 绘画**：真实图像按原比例分成二十四片；拖柄在平面与空间之间展开/重组，光球移动实际灯光与百叶，画轮切换十二幅作品。
- **共振潮汐机 / 音乐**：外侧曲柄驱动共振盘与波形叶片；频率滑臂改变波形和管风琴结构，十四根弦可拨出装置短音。真实歌曲保留精确外链，不把合成音色冒充歌曲。
- **失重竞技穹顶 / 体育**：曲面看台、288个座席、分裂球场、桁架与张力网罩组成空间竞技场。拖球瞄准、松手发射；调整引力环改变预测弹道与后续发射参数；五种目标支持访客小游戏，得分不代表真实比赛。
- **分岔时间织机 / 剧集**：卷轴、叙事窗和三层桥面编织成目录时间轴。拖卷轴浏览真实剧集，分岔开关重接桥梁，摆锤反转时间珠链。装置不伪造剧中剧情。
- **折光剪辑场 / 电影**：胶片穿越导轮、卷盘、齿轮和投影组件。拖动换电影，把作品放进三个剪辑槽、调序，再按拼接杆组成自己的片单；可拖投影镜头改变构图。
- **重力折叠乐园 / 游戏**：旋转五段道路并对齐接口，让六段连接全部接通。门瓣展开后，旅行光球可沿路径抵达终点；抵达后再点击作品进入详情。可复位重玩。
- **记忆编排剧院 / 策展**：七件真实收藏成为双面舞台布景。直接拖框吸附展位会同步改变实际策展顺序；编排轮切换环形、螺旋和线性布局，三组升降机构改变层次并牵动配重和线缆。

## 操作与镜头

按住实际机关时，指针输入由该部件独占；拖空白处才环顾镜头。拖拽在命中点的屏幕平行面上求解，并固定按下时的局部坐标框架，避免移动父对象抵消手势。鼠标和触摸共用 Pointer Events，细小机关使用额外代理体。悬停提示说明动作与结果，可打开编号位置提示。

拾取同时检查当前装置的实体遮挡；隔在机身后的机关不能穿透选择，其场景编号随遮挡隐藏，侧栏仍保留操作入口。提示与键盘操作使用真实握持点的局部锚点。透明拾取代理和透光效果不投射默认的不透明块状阴影。

侧栏首先给出玩法和当前状态，再提供可折叠的键盘操作目录、真实馆藏搜索与详情。机关按钮可用方向键、Enter/Space及步进操作，提供直接拖拽的替代。减少动态模式保留机构结果，跳过持续运动；体育投球直接计算至结果。后台和离开音乐装置时暂停声音。

桌面为模型近景与右侧目录，体育使用较高俯角显示球场内部；手机为上方模型、下方可滚动操作/目录及横向类别导航。全景展示十件装置，可以点选、旋转、缩放和切换日光/月光。

## 工程与性能

纯静态 HTML/CSS/ES Modules，无 npm 构建和运行时外部 CDN。使用仓库内 Three.js r187（MIT），没有新增包依赖。js/world/experiences/ 每类独立模块；sculpt.js 提供缓存倒角几何、齿轮、管线、参数曲面、文字纹理、实例化及微表面材质。

全景用真实模型的静态 BatchedMesh 版本合并同材质绘制，进入时恢复可独立运动的原模型。全景仅在视角或资源变化时重绘，当前装置约30fps更新，限制像素比并降低阴影刷新频率；近景收紧阴影视锥提高细部质量。动态材质、WebAudio、实例缓冲与纹理按生命周期释放。

图像按本地原资源解码。尺寸改变的占位纹理需要先释放旧的 immutable WebGL storage 再上传真实图；普通 TextureLoader 保持原始异步加载流程，避免预先分配错误尺寸。画室各拼片保留独立 UV 变换，复用同一解码图像与 GPU 分配，按自然宽高重新排布。
