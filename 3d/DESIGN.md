# N1GHT CHXN9 · 夜间陈列室

进入时正对馆藏照片《The last red light》。门框、光带与地面接缝向同一张作品收拢，从入口展品可以直接进入摄影。图像、文字与声音、银幕与赛场三组索引同时提供类别直达，「我的展览」独立进入访客策展。旧的 #photo、#books 等地址继续定位到对应展区。

## 看作品和动手操作

桌面将展厅和操作区并排，手机先呈现场景，再显示「操作展品」与「浏览馆藏」。操作区优先给出各展区的主要机关，其他机关可展开，也能直接从场景中操作。可拖动的部件提供步进按钮。馆藏可搜索并查看原始题注、来源和大图。详情打开时保留场景及装置状态，关闭后回到触发控件。移动端展区索引逐行分组，页头入口可从长目录直接跳去其他展区。

摄影透光台以实际照片撑满展面，左右铜拨片换片，底部滑杆调节进光，点照片查看详情。作品保留原始比例。展厅的其他装置按各自作品选择形体、操作和默认观察角度，共用同一套机位、展墙与灯光。深橄榄底色、带暖调的石材和黄铜光带将不同展区连起来，真实作品保留原色。

阅览室按馆藏书名、作者和布面配色生成封面，打开后呈现原有的藏书文字。画室的解构、诗室的诗页、唱片室的拨弦、银幕作品的换片和编排，以及看台和路径实验室的操作，都可以从展品正面发现和触发。

策展从收藏中选最多三张照片和四件其他作品，支持场景与清单内的排序、题签草稿及 PNG 导出。当前浏览器保存选件、顺序和题签。

## 实现

- 三组导航、展区名称、短说明和机位在 js/world/gallery.js。原句、真实媒体和来源继续来自馆藏数据。
- js/world/engine.js 使用现有本地 Three.js。入口单独构建，各展品模块按访问加载，切换时将当前装置放进共享展厅。未访问的装置无需创建几何或加载纹理。入口照片可在 WebGL 准备前直接显示。
- 展厅的默认相机按横向画幅适配。空白处拖动环顾，展品机关接管自己的拖动。操作提示可选，方向键和触摸步进提供等效入口。减少动态模式直接呈现切换结果。
- WebGL 初始化失败或上下文丢失时使用馆藏视图，导航、搜索、详情和策展由 DOM 继续提供。离开展区或标签页进入后台时停止装置声音。
- 本地预览用 node serve.mjs，入口为 http://127.0.0.1:3100/3d/。普通版与 MyScore 分别维持自己的入口。
