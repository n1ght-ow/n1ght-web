# N1GHT CHXN9 · 夜间陈列室

独立的 3D 私人艺术馆位于 /3d/，馆藏涵盖摄影、书籍、诗歌、绘画、音乐、体育、剧集、电影和游戏。入口展品通往摄影区，按组排列的展区索引可直接进入每类收藏。普通首页与 /myscore/ 各有独立页面。

访客可以在场景中操作各展区的展品，也能用操作列表、键盘和步进按钮。每类馆藏支持浏览、搜索和查看详情，图片、题注、原作或原始来源由对应馆藏数据提供。唱片室的装置音色与真实歌曲入口各自有明确操作。

「我的展览」可收入最多三张摄影作品和四件其他作品，调整顺序、填写展览名称与题签并导出 PNG。藏品、次序和题签草稿保存在当前浏览器。WebGL 不可用时可继续通过馆藏视图完成同样的策展流程。

静态 HTML、CSS 和 JavaScript 使用仓库内 Three.js。设计与运行方式见 DESIGN.md，模块接口见 ../js/world/EXPERIENCE_CONTRACT.md。
