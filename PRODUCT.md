# N1GHT CHXN9

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

A personal collection of photographs, books, poems, music, sport, films, series and games. Visitors browse the owner's collection and make a personal exhibition from five collected objects.

## Users

Inferred from the existing site: curious visitors exploring a personal collection, on desktop and phone. The owner has delegated this redesign's visual and implementation decisions.

## Capabilities and Constraints

46 photographs with stable IDs, spatial exploration and a complete index, a three-photo story with PNG export, seven archive tabs, searchable music, book and media details, and a five-object curator with three poster formats and PNG export. Browser-local drafts. Static HTML, CSS and JavaScript with local GSAP, ScrollTrigger and Lenis. No build dependency.

## Brand Commitments

N1GHT CHXN9 is the original name. Existing interface language is English; collection titles keep their original language. The user requests a full redesign using Anthropic Skills and Impeccable and explicitly delegates aesthetic decisions without preserving the incumbent visual rules.

## Evidence on Hand

The existing index.html, js/*-data.js, photo/, hero/, posters/, covers/ and sport/ contain the real collection. Use these assets rather than inventing collection items or personal facts.

## Product Principles

Let the original collection lead. Make browsing and creating enjoyable. Keep original media intact. Preserve keyboard operation and reduced-motion access. Evaluate the built page in a browser.
